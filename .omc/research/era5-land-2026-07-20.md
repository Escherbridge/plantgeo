# ERA5-Land research

- URL: https://cds.climate.copernicus.eu/datasets/reanalysis-era5-land-timeseries?tab=overview
- Retrieved: 2026-07-20
- Intent: validate the initial historical land-state source for the PlantGeo four-year backfill.

ERA5-Land is a global land-surface reanalysis that is available from 1950 to present. The dedicated time-series dataset is an analysis-ready, cloud-optimized subset for long point time series; the documentation describes 0.1-degree retrieval points and a five-day update lag for the time-series product. It is available through the CDS API and supports NetCDF or CSV. Relevant documented variables include 2m temperature, 2m dewpoint temperature, total precipitation, 10m wind components, surface solar radiation, and volumetric soil water in layers 1-3. Copernicus lists the data under CC-BY and assigns DOI 10.24381/cds.e2161bac to the source dataset.

Implementation implications: configure access through a user-provisioned CDS credential, retain the Copernicus dataset/release metadata and retrieval timestamp, select only the defined soil moisture/temperature, evapotranspiration, runoff, and vegetation variables, and hold a refresh buffer for the documented latency/revisions.
