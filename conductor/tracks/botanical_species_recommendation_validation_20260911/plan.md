# Plan

This planning pass adds no model fit, API change, source download or production
recommendation.

## R0 — evidence and receipt freeze

- [ ] Receive accepted occurrence and species-profile releases plus their shared
  canonical taxon authority/version.
- [ ] Freeze environmental products, periods, spatial supports and match
  predicates for each requirement field.
- [ ] Define a recommendation receipt that records every release, rule, missing
  field, conflict, applicability limit and abstention.
- [ ] Keep documented occurrence, establishment compatibility and objective
  effect as separate sections through training, serving and explanation.

## R1 — bounded occurrence baseline

- [ ] Choose a named Pacific Northwest taxon pilot and measure independent
  specimens, duplicate/syndication rate, collection-event clustering, cultivated
  state, temporal precision and spatial uncertainty.
- [ ] Freeze thinning, background/sampling correction, environmental period and
  support rules before deriving any association.
- [ ] Produce a documented-occurrence baseline without calling it suitability or
  turning missing records into absence.

## R2 — compatibility and effect composition

- [ ] Compare reviewed profile requirements with environmental values using
  compatible, incompatible, unknown and not-evaluated component states.
- [ ] Keep long-term establishment compatibility separate from selected-day
  stress and from management-objective effect evidence.
- [ ] Admit species-objective-effect evidence separately; do not infer an effect
  from drought, fire, salt or another tolerance trait.
- [ ] Define fuel-analysis components for tissue water, oils/resins/extractives,
  heat/ash, curing, architecture and fuel-bed behavior without collapsing them
  into fire tolerance; define agricultural roles with the same per-assertion
  evidence discipline.
- [ ] Preserve component verdicts and require reviewed calibration before
  emitting any probability or combined rank.

## R3 — API and agent

- [ ] Return all contributing release identities, component reasons, conflicts,
  missing inputs and abstention states through bounded API and agent responses.
- [ ] Prove the recommendation endpoint through the registered application route
  and the recommendation tool through both model-facing and MCP tools/list and
  tools/call surfaces.

## R4 — integration and independent validation

- [ ] Validate with spatial and temporal blocks plus independent establishment or
  survey evidence appropriate to the claimed recommendation strength.
- [ ] Test taxonomy/cultivar integrity, uncertainty-aware joins, no silent
  substitution, no missing-as-zero and no occurrence-as-suitability behavior.
- [ ] Have `r4` publish the exact-tree integration receipt after the data, model,
  API and agent slices are combined.
- [ ] Obtain the dependency-last `r5` botanical, statistical, safety and agent-
  honesty verdict; the reviewer does not author or integrate the candidate.
