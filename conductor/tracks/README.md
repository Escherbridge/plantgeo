# Historical track catalogue

This directory retains earlier feature concepts, exploratory plans, and
evidence. It is useful for discovery but is not the active PlantGeo roadmap,
release plan, or implementation authority.

Use [`../tracks.md`](../tracks.md) for the current registry and
[`../release-governance.md`](../release-governance.md) for production gates.
The numbered tracks, legacy service scaffold, ingestion, RAG, and strategy-card
documents must be re-scoped into a governed current track before execution.

Historical files are intentionally retained for provenance. Do not infer that a
checked task, a proposed service, or a listed dependency is currently deployed,
approved, or safe to revive.
