# 005: regulatory-classification

## Question

Given US weather-modification and agricultural-product law, when marketing
soil biology with an atmospheric co-benefit, where is the legal line and
which claims cross it?

## Sources (fetched 2026-08-02)

- 15 USC Ch. 9A (Weather Modification Activities or Attempts; Reporting):
  "No person may engage, or attempt to engage, in any weather modification
  activity in the United States unless he submits to the Secretary [of
  Commerce]" a report — NOAA Form 17-4, due >= 10 days before activities.
  https://uscode.house.gov/view.xhtml?path=/prelim@title15/chapter9A&edition=prelim
- Colorado example of state layer: permit required to modify weather
  (CRS 36-20-112); permits reference NOAA reporting; contractor + operational
  plan regime. https://cwcb.colorado.gov/focus-areas/supply/weather-modification-program
- FIFRA: microbial PESTICIDE registration (40 CFR 152; data requirements
  40 CFR 158 Subpart V) — triggered only by pesticidal claims.
  https://www.epa.gov/pesticide-registration/biopesticide-registration
- FDA CPG Sec. 689.100 Direct-Fed Microbial Products: unlisted direct-fed
  microbials risk unapproved-food-additive / new-animal-drug status; GRAS
  notice or AAFCO ingredient listing is the compliance path.
  https://www.fda.gov/regulatory-information/search-fda-guidance-documents/cpg-sec-689100-direct-fed-microbial-products

## The line

Federal and state weather-modification regimes attach to the ACTIVITY of
intentionally modifying weather. A soil/feed product marketed on agronomic
claims, whose spores happen to be IN-active, is an agricultural product.
Marketing it to change precipitation makes the seller a weather modifier:
federal reporting, state permits, and tort exposure (hail/precip litigation
precedent against seeders) attach.

## Classification per product line

| Line | Regime | Compliance path | Forbidden claims |
|------|--------|-----------------|------------------|
| P1 soil amendment | State fertilizer/soil-amendment law (AAPFCO-style); FIFRA only if pesticidal claims | State registration; agronomic label | rain, snowpack, weather, climate, drought relief |
| P2 growth media | Same as P1 (consumer/hort channel) | Same | same |
| P3 animal feed | FDA CVM + AAFCO ingredient system | GRAS notice or AAFCO listing for the organism; M. alpina listing status must be verified | any weather claim; unverified health claims |
| P4 municipal compost | Waste/compost regs + bioaerosol occupational rules | existing facility permits | same weather-claim bar |
| Cell-free IN protein | State soil-additive law; FIFRA only if pesticidal | simplest: no live organism | same weather-claim bar |

Internal/R&D communication is not immune: documented INTENT to modify weather
plus field activity can satisfy the statute even if the label is silent. Any
field pilot that measures precipitation outcomes should file NOAA Form 17-4
defensively — counsel to confirm.

## Verdict: VALIDATED (the line is mappable and the product fits inside it)

### What worked
- A clean compliance perimeter exists: agronomic claims + state ag-product
  registration, with the atmospheric effect treated as an unclaimed
  externality. The P3 feed line has a defined (if slow) GRAS/AAFCO path.

### What didn't / risks
- The entire perimeter collapses the moment marketing promises rain. This is
  a marketing-discipline requirement, and it must survive contact with
  future revenue pressure.
- State weather-mod statutes vary; any state-by-state launch needs a
  50-state survey (not done here).

### Recommendation for the real build
Write the permitted/forbidden claims list into brand guidelines BEFORE any
product exists; retain counsel for the P3 GRAS question and the 50-state
survey; treat NOAA 17-4 filing as mandatory for any instrumented field pilot.
