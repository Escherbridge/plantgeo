# Seasonal Forecast Scoping Report (SEAS5 / C3S)

## 1. Overview
Copernicus Climate Data Store (CDS) provides seasonal forecasts generated by ECMWF (SEAS5) and international partner originating centers (Météo-France, DWD, CMCC, NCEP, JMA, UK Met Office).

## 2. CDS Dataset Details
- **Dataset Identifier**: `seasonal-monthly-single-levels` (and `seasonal-original-single-levels` for sub-daily/raw forecast steps).
- **Originating Centers**: `ecmwf` (SEAS5), `meteo_france`, `dwd`, `cmcc`, `ncep`, `ukmo`, `jma`.
- **Variables**: `2m_temperature`, `total_precipitation`, `sea_surface_temperature`, `10m_u_component_of_wind`, `10m_v_component_of_wind`.
- **Temporal Horizon**: Issued monthly (1st of each month), forecasting up to 6 months ahead (7-month lead window).
- **Spatial Resolution**: 1.0° x 1.0° global grid (or native 0.25° for raw SEAS5).

## 3. Integration Requirements & Structural Parity
1. **Credentials & Endpoint**: Hosted on classic CDS (`cds.climate.copernicus.eu`). Reuses existing `CDSAPI_URL` and `CDSAPI_KEY` infrastructure without requiring new credentials.
2. **Forecast Model Schema**: Integrated using `ForecastModel` with `model_kind='ensemble'` and `model_purpose='metric_forecast'`.
3. **Queue Latency & Cardinality**: High multi-member payload sizes (SEAS5 has 51 ensemble members). Retrieval should extract pre-computed ensemble statistics or reduce to quantiles (`p10`, `p50`, `p90`) at ingest time into `ForecastValue.quantile_values`.
