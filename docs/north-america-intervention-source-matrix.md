# North American intervention data source matrix

Verified against provider material on **2026-07-23**. This register is an
ingestion allowlist candidate, not a claim that every source is ready for
redistribution. `S`, `P`, `N`, `C`, and `R` mean structure, parcel/property,
neighborhood, city/landscape, and regional support. A source clipped to a
smaller geometry keeps its native support; clipping never creates precision.

## Governance decisions from the matrix

- A North American adapter registry must store country, jurisdiction,
  `coverage_geometry`, coverage/completeness class, native scale/resolution,
  temporal support, latency, licence snapshot/checksum, attribution, access
  policy, and maximum inference scale.
- `unknown` is a valid result. Missing parcels, buildings, wells, hydrants, or
  regulations must never be filled by coarser proxies.
- Raw observed/provider facts, model-derived features, recommendation records,
  confidence, and known gaps remain separate relations. This workstream creates
  facts/features/gaps only.
- Structure support requires validated authoritative/local geometry or reviewed
  1–2 m data. Parcel support requires a jurisdiction-approved parcel/property
  geometry plus an input whose native support is genuinely parcel-compatible.
